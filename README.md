# robosys2025
標準入力から指定された形式で入力された食べ物リストであるテキストを読み込み、カロリーの合計を出力するコマンドです。また、カロリーが日本人男性の一日のカロリー摂取量の基準値である2650kcalを超えると警告が出力されます。
